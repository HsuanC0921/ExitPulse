# 介面驗證（2026-11-18）

本頁下方記錄早期品牌與手機驗證。目前前端使用 4200，API 使用 5011。最新樣式見 [DESIGN.md](../DESIGN.md)，驗證見 [審查](AUDIT.md)。

## 品牌與 typeset

桌機與手機改用同一個 `app-brand`：白色站牌底的脈衝 SVG、ExitPulse 字標與繁體中文副標。品牌維持黑白，路線色仍用於資料。

字標採 Barlow Semi Condensed，Exit 為 700、Pulse 為 800，字距 −0.025em；中文沿用 Noto Sans TC 600。字型由 Google Fonts 載入，使用 `display=swap`，並保留中文字型與 sans-serif 後備。

| 角色 | 桌機 | 手機 |
| --- | --- | --- |
| 脈衝標誌 | 36 × 36px | 32 × 32px |
| ExitPulse | 30px | 26px |
| 中文副標 | 12px、行高 1.6 | 同左 |

已在瀏覽器實際檢視 1440 × 900、390 × 844、320 × 740 的明暗模式。320px 的品牌與地圖／清單切換間距約 34px，中文副標的內容寬度與容器同為 100px，沒有裁切。切換按鈕高度為 44px，各尺寸沒有整頁橫向溢出。瀏覽器確認 Barlow Semi Condensed 700、800 已載入；新頁面主控台沒有錯誤。

`impeccable detect --json --scope type apps/web/src/app` 回傳 `[]`。這是機械檢查結果；字標、行距、窄寬度與明暗對比另以實際畫面確認，沒有把掃描結果換算成虛構分數。

## 同一輪已完成的介面調整

- 手機以地圖、清單、條件與詳情四種畫面狀態操作，共用查詢資料；不再把整份桌機面板塞進底抽屜。
- 721–1100px 選取站對後以詳情取代左側清單，保留地圖空間。
- 品牌與站名牌的樣式分開，修正南港與南港展覽館重疊。
- 單站、全網提供單日逐時時間軸，可用鍵盤或拖曳選取小時，並可播放、暫停及切回全天。月份輪播另列，避免和單日播放混淆。
- 人流提示改為點開後顯示當前模式的標籤／數值圖例，避免窄框長段落。
- 每日日曆改為七欄；歷年月圖保留可點選的月份寬度，改用橫向捲動。
- 查詢失敗保留條件並提供重試，不再把請求失敗直接說成沒有資料。

前端 18 項模型測試通過；正式 `ng build` 通過，未放寬容量限制。剩餘建置警告為既有 MapLibre CommonJS 相依。

時間軸驗證包含：全網 2026-09-01 的 7–8 點與 8–9 點 API 分別回傳 166,541、266,514 人次，皆為 119 站；手機滑桿可由 7 點切到 8 點，網址同步為 `h=8-9`，播放按鈕可切入暫停狀態。另從 0 點開始完整播放到 23 點，按鈕恢復未播放狀態、沒有殘留載入或失敗訊息，地圖 canvas 仍存在。逐時圓圈使用固定尺度，避免各小時重新正規化而抹去人次差異。
